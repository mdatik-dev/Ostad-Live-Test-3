# Temperature Converter App

A Flutter application for converting temperatures between Celsius and Fahrenheit.

## Features

- Celsius to Fahrenheit conversion.
- Fahrenheit to Celsius conversion.
- Input validation for empty and invalid values.
- Results displayed up to 2 decimal places.
- Responsive, clean Material 3 interface.
- Reset button to clear the input and result.
- Uses Flutter's built-in `setState` for state management.
- No database, Firebase, or Supabase required.

## Conversion formulas

- Celsius to Fahrenheit: `F = (C × 9/5) + 32`
- Fahrenheit to Celsius: `C = (F - 32) × 5/9`
